# 🎯 MORSE88

A single-file Morse translator — International Morse for English, and a proposed
frequency-based Morse mapping for Arabic (MC88).

**[▶ Open the tool](./index.html)** · Free · Offline · No tracking

---

## What it does

- **English → Morse** using the International Morse standard.
- **Arabic → Morse** using the MC88 Arabic mapping (see table below).
- **Morse → text** in either direction.
- Full dictionary visible in the app · Copy · Download · Light/dark theme.

## The MC88 Arabic mapping

Rule: **the more frequent the letter in Arabic, the shorter its code.**

| Length | Letters |
|---|---|
| 1 | ا (`.`), ل (`-`) |
| 2 | م، ن، و، ي |
| 3 | ر، ت، ب، ه، د، س، ع، ف |
| 4 | ق، ح، ج، ش، ة، ص، ط، ك، خ، ز، ض، ذ، ث، غ، ظ، ى |
| 5 | ء |

Normalization before encoding: أ، إ، آ → ا · ؤ → و · ئ → ي · diacritics ignored.
Digits and punctuation follow International Morse. `/` separates words.

Frequency ordering is **approximate** — based on published MSA corpora
(Penn Arabic Treebank, KSU Corpus, ArabiCorpus). Different corpora rank
mid-frequency letters slightly differently.

## What this is not

- Not an official standard. Not ratified by any body. Just a proposed system.
- Not a claim that no Arabic Morse table existed before. If one did and I missed
  it, tell me — I'll credit it here.
- Not a copyright claim over the *idea* of Arabic Morse. Only over this table,
  this code, and this documentation.

## ماذا تفعل

- **إنجليزي → مورس** بالمورس الدولي.
- **عربي → مورس** بخريطة MC88 (الجدول أدناه).
- **مورس → نص** في الاتجاهين.
- القاموس كامل ظاهر في الأداة · نسخ · تنزيل · وضع فاتح/داكن.

## خريطة MC88 العربية

القاعدة: **كلما زاد تكرار الحرف في العربية، قصر رمزه.**

| الطول | الحروف |
|---|---|
| 1 | ا (`.`)، ل (`-`) |
| 2 | م، ن، و، ي |
| 3 | ر، ت، ب، ه، د، س، ع، ف |
| 4 | ق، ح، ج، ش، ة، ص، ط، ك، خ، ز، ض، ذ، ث، غ، ظ، ى |
| 5 | ء |

التطبيع قبل الترميز: أ، إ، آ ← ا · ؤ ← و · ئ ← ي · التشكيل يُتجاهل.
الأرقام والترقيم بالمورس الدولي. `/` تفصل الكلمات.

ترتيب التكرار **تقريبي** — مبني على مدوّنات عربية فصحى منشورة
(Penn Arabic Treebank، KSU Corpus، ArabiCorpus). المدوّنات تتفاوت
قليلًا في ترتيب الحروف المتوسطة.

## ما هذا المشروع ليس

- ليس معيارًا رسميًا، ولا مصادقًا عليه من أي جهة. مجرد نظام مقترح.
